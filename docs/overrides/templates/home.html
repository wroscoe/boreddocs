boreddocs

Free, SEO- and AI-friendly static site for school board documents — agendas, minutes, and policies authored in Markdown. Like mkdocs, but specialized for the way school boards actually publish information.

View on GitHub pip install boreddocs

What is this?

School board agendas, minutes, and policies are public records — but most districts publish them through paid portals that are expensive, hostile to search engines, and unfriendly to AI assistants. boreddocs is the free, open-source replacement: each district authors its content in Markdown in a GitHub repository, and boreddocs build renders a fully pre-rendered static site that can be hosted on GitHub Pages for $0.

Editor mental model: a district's repo is just Markdown + one config file. No Python, no templates, no frameworks. pip install boreddocs takes care of the rest.

Quickstart

pip install boreddocs
boreddocs new my-district
cd my-district
boreddocs serve              # preview at http://localhost:8000
boreddocs build              # → _site/, ready for GitHub Pages

The bundled boreddocs new scaffold ships a working "Sample School District" with a real agenda, real minutes (motion blocks and all), and sample policies — clone, deploy, then replace the content.

How it works

  • Markdown content: content/meetings/2026-04-15-regular.md, content/policies/AA.md. Frontmatter (YAML) for metadata, body for content.
  • Heading conventions: # 1. Section → numbered section (orange bar), ## A. Item → lettered sub-item (blue bar), matching the typical board-portal outline.
  • The ::motion directive: a single Markdown block produces a fully styled voting record (motion text, mover, seconder, per-member yes/no). See an example on the TCSD #1 minutes page.
  • Pre-rendered HTML: every page is plain HTML at deploy time — no client-side rendering, so search engines and AI scrapers index everything.
  • Theme overrides: drop a file in overrides/templates/ or overrides/static/ and it shadows the default theme. (This very page is built that way.)
  • Two clicks to edit: every page has a "View source" + "Edit this page on GitHub" link in the footer pointing at the source .md.

Live example

Teton County School District #1 — TCSD's full board-doc site, including agendas, minutes with motion blocks, and the Board Policy Manual. Their entire repository is ~14 files: a config, the Markdown content, and a 30-line GitHub Actions workflow. Everything else lives in boreddocs.

Status

Pre-1.0. The frontmatter contract (schema_version: 1) is stable for the duration of 0.x. Breaking changes require a major bump and a documented migration. See the changelog.

Install

PyPI:

pip install boreddocs
