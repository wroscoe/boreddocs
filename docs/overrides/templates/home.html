Why districts switch

Free forever

No subscription fees, no per-user charges. Hosted free on GitHub.

Easy to update

Edit a meeting's agenda right in your web browser — no software, no FTP. Click "Edit", type, click "Commit". The site updates within a minute.

Found by search engines and AI

Every page is indexed by Google, Bing, and AI assistants. Your community can actually find what they're looking for.

Looks great on every device

Phone, tablet, desktop — readable, responsive, and clean. Designed for the people who use it most: parents.

You own your data

Your agendas live in your own GitHub repository. Export, archive, or move them whenever you want — no vendor lock-in.

Open source

Source code is public, MIT-licensed, and audited by anyone who cares to look. No black boxes.

How it works

  1. Click "Get started" — a copy of the starter site is created in your GitHub account. (You'll need a free GitHub account.)
  2. Add your district's name and first agenda — edit a few text files right in GitHub's web UI. The starter README walks you through it.
  3. Save your changes — your site is live within a minute. Add a custom domain when you're ready.

Ready to start?

The whole setup takes about five minutes. You can change everything later.
